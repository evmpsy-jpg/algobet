# Roadmap

## Stage 5.1 — готово
Архитектура `Excel → ParsedMatch → MatchData → SignalDecision → Signal`, нормализация, Rule Engine, вероятности `CV/CW`, уровни сигналов, шаблон и конфигурации.

## Stage 5.2 — готово
Decision Trace, Decision Log в базе, объяснение решения в админке, ручной пересчёт сигнала, сохранение версии алгоритма.

## Stage 5.3 — готово
Пользовательские доступы, trial на 3 сигнала, paid-доступ вручную, реальные Telegram-доставки, история доставок, retry failed/missing, интеграционный Excel → delivery тест.

## Stage 5.4 — готово
Админка доставок: общий список, фильтры `sent/failed`, повторная отправка selected failed/missing, CSV-экспорт доставок и отчетов.

## Stage 5.5 — готово
Результаты матчей, ручная и автоматическая фиксация исходов сигналов, базовая статистика качества, фильтры по результатам, CSV-экспорт.

## Stage 6.0 — MVP готов
VPS/Docker запуск, SQLite на сервере, web-админка с HTTP Basic Auth для нескольких админов, тарифы, заявки на подписку и анализ, ручной режим оплаты, управление доступами, настройки реквизитов/контактов, мониторинг, журнал действий админов и CSV-экспорты.

## Оставлено в ручном режиме
Оплата остается ручной: пользователь создает заявку, получает реквизиты и контакт, админ вручную подтверждает оплату и выдает доступ.

## Следующие этапы
- PostgreSQL и Alembic-миграции вместо SQLite для роста проекта.
- Усиление защиты web-админки: HTTPS, ограничение по IP или reverse proxy.
- Расширенный мониторинг: логи приложения, алерты о падении бота, контроль свободного места.
- Документация рабочих процессов для админов.
- API или интеграции оплаты — только если позже решим уходить от ручной оплаты.
