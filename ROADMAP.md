# Roadmap

## Stage 5.1 — готово
Архитектура `Excel → ParsedMatch → MatchData → SignalDecision → Signal`, нормализация, Rule Engine, вероятности CV/CW, уровни сигналов, шаблон и конфигурации.

## Stage 5.2 — готово
Decision Trace, Decision Log в базе, объяснение решения в админке, ручной пересчёт сигнала, сохранение версии алгоритма.

## Stage 5.3 — готово для MVP
Пользовательские доступы, trial на 3 сигнала, paid-доступ вручную, реальные Telegram-доставки, история доставок, retry failed/missing, интеграционный Excel → delivery тест.

## Stage 5.4
Улучшение админки доставок: общий список доставок, фильтры sent/failed, повторная отправка выбранной failed-доставки, экспорт отчёта.

## Stage 5.5
Реальные результаты матчей, фиксация исходов сигналов, базовая статистика качества.

## Stage 6.0
PostgreSQL, миграции, web-admin, тарифы, оплата, API.
