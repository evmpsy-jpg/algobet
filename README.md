# АлгоБет — первый локальный этап

Рабочий каркас Telegram-бота для ручной загрузки турнирной Excel-таблицы, немедленного анализа и последующей выдачи сигналов за 20 минут до матча.

## Что уже работает

- `/start` и регистрация пользователя в SQLite.
- Главное меню.
- Закрытая админ-панель для Telegram ID `315715137`.
- Загрузка `.xlsx` через Telegram.
- Чтение листа `Турниры`.
- Разбор формул `HYPERLINK` из столбца C.
- Извлечение ID турнира, ID матча, игроков, рейтингов, даты и времени.
- Сохранение всех значений строки в `raw_data`.
- Обновление существующего матча по постоянному ID матча.
- Пометка матчей, которых нет в свежем файле.
- История каждого импорта и снимок данных матча.
- Каркас анализа сигналов сразу после загрузки.
- Расчёт будущего времени отправки `начало матча − 20 минут`.
- Фоновая проверка наступивших отправок.

Сейчас `signal_rules.py` специально возвращает `suitable=False`, поскольку условия отбора и шаблон сообщения ещё не предоставлены. Поэтому после первой загрузки будет `Запланировано сигналов: 0` — это ожидаемо.

## Установка на Windows 11

Откройте PowerShell в папке проекта.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если PowerShell запрещает активацию скриптов, выполните один раз в текущем окне:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## Настройка

Скопируйте `.env.example` в `.env`:

```powershell
Copy-Item .env.example .env
```

Откройте `.env` и замените:

```env
BOT_TOKEN=PASTE_TOKEN_FROM_BOTFATHER
```

на настоящий токен бота. Токен не публикуйте и не загружайте в GitHub.

Ваш администратор уже указан:

```env
ADMIN_IDS=315715137
```

## Запуск

```powershell
python run.py
```

Затем откройте бота в Telegram:

1. Нажмите `/start`.
2. Откройте `⚙️ Админ-панель`.
3. Выберите `📥 Загрузить таблицу`.
4. Отправьте файл `.xlsx`.

## Где лежат данные

- База SQLite: `data/algobet.db`
- Загруженные Excel-файлы: `uploads/`

## Как обновляется матч

Основной ключ — `external_match_id`, извлечённый из ссылки вида:

```text
https://www.sport-liga.pro/ru/table-tennis/tournaments/75175/692495
```

Здесь:

- ID турнира: `75175`
- ID матча: `692495`

При следующей загрузке запись с ID матча `692495` обновляется свежими игроками, коэффициентами, временем и остальными показателями. После обновления правила сигнала запускаются повторно.

## Следующий этап

После получения условий отбора нужно изменить только:

```text
app/services/signal_rules.py
```

После получения шаблона сообщения — функцию `build_signal_message()` в том же файле.

После этого подключаются подписки и тестовые три сигнала, чтобы фоновый процесс отправлял сигнал только пользователям с доступом.

## Настройка правил без изменения Python-кода

Основные пороги находятся в файле `signal_rules.yaml`:

- `min_h2h_games` — минимум очных игр из CP;
- `min_favorite_form` — минимум формы Q/X;
- `min_bg_p1` — стоп-фильтр BG для сигнала на П1;
- `min_bf_p2` — стоп-фильтр BF для сигнала на П2;
- `high_confidence.min_probability` — граница ЖБ-сигнала по готовой вероятности CV/CW;
- `lead_minutes` — за сколько минут до матча отправлять сигнал.

После изменения правил загрузите Excel повторно: актуальная таблица пересчитает и обновит очередь сигналов.
Администратор при просмотре сигнала видит тот же текст, который получит пользователь.
