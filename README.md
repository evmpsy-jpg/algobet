# АлгоБет — MVP Telegram-выдачи сигналов

Telegram-бот для ручной загрузки турнирной Excel-таблицы, анализа матчей по настраиваемым правилам и выдачи сигналов пользователям с доступом.

## Что уже работает

- `/start` и регистрация пользователя в SQLite.
- Главное меню пользователя.
- Закрытая админ-панель для Telegram ID `315715137`.
- Загрузка `.xlsx` через Telegram.
- Чтение листа `Турниры`.
- Разбор формул `HYPERLINK` из столбца C.
- Извлечение ID турнира, ID матча, игроков, рейтингов, даты и времени.
- Сохранение всех значений строки в `raw_data`.
- Обновление существующего матча по постоянному ID матча.
- Пометка матчей, которых нет в свежем файле.
- История каждого импорта и снимок данных матча.
- Нормализация Excel-строки в `MatchData` через `excel_mapping.yaml`.
- Rule Engine с вероятностями `CV/CW`, выбором стороны и правилом равных вероятностей.
- Decision Trace и постоянный Decision Log по каждому матчу.
- Формирование `ScheduledSignal` и текста сообщения по `templates/signal.txt`.
- Фоновая отправка наступивших сигналов.
- Ручная отправка выбранного сигнала из админки.
- Trial-доступ на первые 3 сигнала.
- Ручное управление доступами пользователя: trial, paid, отключение.
- Тарифы подписок: VIP, все сигналы, всё включено.
- Ручной режим оплаты через заявку, реквизиты и подтверждение админом.
- Заявки на подписку и анализ матча.
- История доставок `SignalDelivery`: sent / failed / pending.
- Retry для failed/missing доставок без дублей уже успешных отправок.
- Админский просмотр трассировки решения и доставок по сигналу.
- Web-админка с логином/паролем для нескольких админов.
- Web-разделы: сводка, сигналы, доставки, статистика, мониторинг, пользователи, подписки, заявки, настройки, журнал.
- CSV-экспорты сигналов, доставок, подписок, заявок и журнала действий.
- VPS/Docker Compose запуск бота и web-админки.
- SQLite backup и контроль хранения загруженных файлов.
- Отображение времени в админке в часовом поясе `TIMEZONE`.

## Установка на Windows 11

Откройте PowerShell в папке проекта.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если PowerShell запрещает активацию скриптов, выполните один раз в текущем окне:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## Настройка

Скопируйте `.env.example` в `.env`:

```powershell
Copy-Item .env.example .env
```

Откройте `.env` и укажите настоящий токен бота:

```env
BOT_TOKEN=PASTE_TOKEN_FROM_BOTFATHER
ADMIN_IDS=315715137
TIMEZONE=Europe/Moscow
```

Токен не публикуйте и не загружайте в GitHub.

## Запуск

```powershell
python run.py
```

Затем откройте бота в Telegram:

1. Нажмите `/start`.
2. Откройте `⚙️ Админ-панель`.
3. Выберите `📥 Импорт Excel`.
4. Отправьте файл `.xlsx` с листом `Турниры`.
5. Откройте `📊 Сигналы` и проверьте созданные сигналы.

## Проверка отправки

Для ручного теста без ожидания времени матча:

1. Выдайте пользователю доступ: `⚙️ Админ-панель` → `👥 Пользователи` → открыть пользователя → `🎁 Выдать trial 3` или `💳 Выдать paid`.
2. Откройте `📊 Сигналы`.
3. Зайдите в `🟢 Запланированные` или `🟡 Готовые`.
4. Откройте сигнал.
5. Нажмите `🚀 Отправить пользователям сейчас`.
6. Проверьте результат в `📬 Доставки`.

Для уже отправленных сигналов доступна кнопка `🔁 Повторить failed/missing`: она повторяет только неуспешные или отсутствующие доставки и не дублирует уже успешные.

## Где лежат данные

- База SQLite: `data/algobet.db`
- Загруженные Excel-файлы: `uploads/`
- Настройка колонок: `excel_mapping.yaml`
- Настройка правил: `signal_rules.yaml`
- Шаблон сигнала: `templates/signal.txt`

## Как обновляется матч

Основной ключ — `external_match_id`, извлечённый из ссылки вида:

```text
https://www.sport-liga.pro/ru/table-tennis/tournaments/75175/692495
```

Здесь:

- ID турнира: `75175`
- ID матча: `692495`

При следующей загрузке запись с ID матча `692495` обновляется свежими игроками, временем и показателями. После обновления правила запускаются повторно, сохраняется новый Decision Log и обновляется очередь сигналов.

## Настройка правил без изменения Python-кода

Основные пороги находятся в файле `signal_rules.yaml`:

- `min_h2h_games` — минимум очных игр из CP;
- `min_favorite_form` — минимум формы Q/X;
- `min_bg_p1` — фильтр BG для сигнала на П1;
- `min_bf_p2` — фильтр BF для сигнала на П2;
- `levels.top.min_probability` — граница TOP-сигнала;
- `levels.strong.min_probability` — граница STRONG-сигнала;
- `lead_minutes` — за сколько минут до матча отправлять сигнал.

После изменения правил загрузите Excel повторно: актуальная таблица пересчитает и обновит очередь сигналов.
